# 🍳 מה מבשלים היום?

אתר מתכונים סטטי בעברית שמשתמש ב־[TheMealDB API](https://www.themealdb.com/api.php), API חינמי שלא דורש הרשמה.

## מה אפשר לעשות באתר
- חיפוש מתכונים לפי שם מנה או לפי מרכיב (גם בעברית, למילים נפוצות)
- עיון לפי קטגוריות (עוף, קינוחים, פסטה, טבעוני...)
- מתכון אקראי בלחיצת כפתור
- צפייה במתכון מלא: מרכיבים, אופן הכנה וסרטון ב־YouTube
- שמירת מתכונים במועדפים (נשמרים בדפדפן)

## איך מריצים
פותחים את `index.html` בדפדפן. צריך חיבור לאינטרנט.

## קריאות ל־API שבשימוש
| כתובת | שימוש |
|---|---|
| `search.php?s=` | חיפוש לפי שם מנה |
| `filter.php?i=` | חיפוש לפי מרכיב |
| `filter.php?c=` | מתכונים בקטגוריה |
| `categories.php` | רשימת קטגוריות |
| `lookup.php?i=` | מתכון מלא לפי מזהה |
| `random.php` | מתכון אקראי |

נבנה בעזרת AI.
